## Подбор цветовых масок на видео

Скрипт `color_mask_tuner.py` помогает подобрать HSV-маски для шариков на `.mp4` видео.
Он показывает исходный кадр, бинарную маску и наложение маски на видео.

Запуск:

```bash
python3 color_mask_tuner.py /path/to/video.mp4
```

Сохранить маски в другой файл:

```bash
python3 color_mask_tuner.py /path/to/video.mp4 --masks masks/balls_hsv.json
```

Горячие клавиши:

- `Space` - пауза / продолжить видео.
- `A` / `D` - кадр назад / кадр вперед на паузе.
- `Z` / `X` - перемотка назад / вперед на 1 секунду.
- `[` / `]` - предыдущий / следующий цвет.
- `1..9` - выбрать цвет по номеру.
- `S` - сохранить маски в JSON.
- `H` - вывести подсказку в терминал.
- `Q` или `Esc` - выйти.

В окне `controls` двигай HSV-трекбары:

- `H/S/V min` и `H/S/V max` - основной диапазон цвета.
- `H2/S2/V2 min` и `H2/S2/V2 max` - второй диапазон, нужен в основном для красного.
- `Use H2` - включить второй диапазон.
- `Blur`, `Open`, `Close` - сглаживание и очистка шума.
- `Min area` - минимальная площадь найденного объекта.
- `Frame` - ручная перемотка по видео.

По умолчанию есть заготовки для `red`, `blue`, `white`, `yellow`, `green`, `orange`.
После нажатия `S` файл `color_masks.json` можно использовать в следующих скриптах детекции.
